# 1. Предметная область

## 1.1. Тема и обоснование выбора

**Тема проекта:** «Bite» — прогрессивное веб-приложение (PWA) для учёта суточного потребления калорий и макронутриентов (КБЖУ) с автоматическим распознаванием продуктов по фотографии.

**Актуальность.** Согласно данным ВОЗ, более 1,9 млрд взрослых имеют избыточный вес. Контроль рациона признан ключевым инструментом профилактики неинфекционных заболеваний. Существующие решения (MyFitnessPal, FatSecret) требуют ручного ввода и поиска продуктов в базе данных, что является основным барьером регулярного использования. Применение мультимодальных LLM (Gemini, GPT-4o) позволяет автоматизировать распознавание блюда и оценку нутриентного состава по одному снимку, сокращая время фиксации приёма пищи с 30–60 секунд до 3–5 секунд.

**Целевая аудитория:**

- люди, ведущие учёт КБЖУ для похудения, поддержания массы или набора мышечной массы;
- пользователи мобильных устройств, для которых критичен offline-доступ и быстрый ввод данных;
- спортсмены-любители, отслеживающие потребление белка.

## 1.2. Бизнес-цели

| ID | Бизнес-цель | Метрика успеха |
|----|-------------|----------------|
| BG-1 | Снизить время добавления продукта в дневник | < 5 c (фото) vs 30–60 c (ручной ввод) |
| BG-2 | Обеспечить работу без постоянного интернет-соединения | offline-доступ к истории и форме ввода |
| BG-3 | Минимизировать стоимость владения за счёт BaaS | отсутствие выделенного сервера |
| BG-4 | Достичь точности распознавания «верное название блюда» | ≥ 80 % на тестовом датасете |

## 1.3. Глоссарий предметной области

| Термин | Определение |
|--------|-------------|
| **КБЖУ** | Калорийность, белки, жиры, углеводы — основные показатели нутриентного состава продукта |
| **BMR** (Basal Metabolic Rate) | Базовый метаболизм — минимальный расход энергии в состоянии покоя, ккал/сут |
| **TDEE** (Total Daily Energy Expenditure) | Суммарный суточный расход энергии с учётом физической активности, ккал/сут |
| **Mifflin–St Jeor** | Формула расчёта BMR, рекомендованная Американской диетологической ассоциацией с 2005 г. |
| **Harris–Benedict** | Альтернативная формула BMR (1919, ревизия 1984 г.) |
| **Уровень активности** | Коэффициент, на который умножается BMR для получения TDEE (sedentary…veryHigh) |
| **Цель** (Goal) | Параметр пользователя: похудение (loss, дефицит −500 ккал), поддержание (maintain), набор (gain, +400 ккал) |
| **Eaten Product** | Запись о съеденном продукте (имя, КБЖУ, дата, фото, статус анализа) |
| **PWA** (Progressive Web App) | Веб-приложение с поддержкой установки, push-уведомлений и offline-режима через Service Worker |
| **BaaS** (Backend-as-a-Service) | Модель поставки бэкенда (Supabase: Postgres + Auth + Storage + Edge Functions) |
| **LLM** (Large Language Model) | В контексте проекта — мультимодальная модель Google Gemini 3 Flash через OpenRouter |
| **RLS** (Row-Level Security) | Механизм Postgres, ограничивающий доступ к строкам таблицы на уровне СУБД |
| **Edge Function** | Serverless-функция на Deno, исполняющаяся на CDN-узлах Supabase |
| **Realtime** | Подписка на изменения строк Postgres через WebSocket-канал Supabase |

## 1.4. Существующие аналоги

| Продукт | Сильные стороны | Слабые стороны |
|---------|-----------------|-----------------|
| MyFitnessPal | Большая база продуктов | Ручной поиск; платный фото-анализ; нет offline |
| FatSecret | Бесплатное API | Устаревший UX; нет авто-распознавания |
| Yazio | Удобный UI | Платная подписка для расширенных функций |
| **Bite** | Фото-анализ из коробки, PWA, offline, бесплатно | Ограничен квотой OpenRouter, нет соц-функций |

## 1.5. Краткая постановка задачи

Реализовать PWA, которое:

1. позволяет аутентифицированному пользователю фиксировать приёмы пищи путём загрузки фотографии;
2. отправляет фото в Edge Function `analyze-food-photo`, которая через LLM-провайдера получает структурированный JSON с КБЖУ;
3. обновляет запись о продукте в Postgres; UI получает обновление по Realtime-каналу;
4. рассчитывает дневные цели по КБЖУ на основании анкеты пользователя (BMR → TDEE → цель);
5. визуализирует прогресс за день, неделю и историю.
